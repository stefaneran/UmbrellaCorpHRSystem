# Umbrella Corp HR System

This is the HR System used by Umbrella Corp to manage the employees in their secret underground facillity where they conduct experiments to develop bio-weapons to be sold to the highest bidder.
You are Claire Redfield, the new HR assistant. You have the abillity to send and receive emails with your colleagues, view/create/edit/delete employees from the system, and throw a pizza party.
Once you log in, make sure to check your emails for your responsibilities. Some might be important enough to need your access elevated to Admin role for... extra options.

# Prerequisites 

Visual Studio version that supports .NET 10

# Setup

1) Open the .sln file with Visual Studio 

2) Run `Update-Database` in the Package Manager Console to apply migrations

3) Run the project (Press F5)
